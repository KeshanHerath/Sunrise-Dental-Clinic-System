# Sunrise Dental Clinic System

A Java-based appointment and patient management system developed for Sunrise Dental Clinic.

## Features

- User authentication with username and password
- Register new patient appointments
- Store patient and appointment information
- Search appointment details using appointment number
- Display patient and appointment information
- Calculate treatment bills
- Print billing information

## Information Stored

- Appointment number
- Patient name
- Address
- Contact number
- Dentist name
- Treatment type
- Appointment date
- Appointment time

## Technologies Used

- Java
- Eclipse IDE
- Git
- GitHub

## How to Run

1. Download or clone the repository.
2. Open the project in Eclipse.
3. Open `SunriseDentalClinic.java`.
4. Run the program as a Java Application.

## Project

This project was developed as a computerized solution to improve appointment and patient management at Sunrise Dental Clinic.
